# Использование мод-шаблона с Xcode

![DDLC Mod in Xcode](https://marquiskurt.net/images/covers/2019-06-09-cover.png)

Этот шаблон поддерживает сборку/запуск через Xcode, что освещено в этом руководстве Ren'Py/Xcode: https://web.archive.org/web/20230606025553/https://marquiskurt.net/2019/06/09/post.html.

Но перед тем, как запускать проект, есть пара вещей, которые *нужно* настроить, дабы он запускался корректно.

## Измените переменную `RENPY_TOOL`

В файле **Config.xcconfig** измените значение переменной `RENPY_TOOL` на каталог, куда установлен Ren'Py. Например:

```xcconfig
// Измените строку ниже так, чтобы она указывала на реальный путь установки Ren'Py!
//RENPY_TOOL=/какой_то/каталог/renpy/renpy.sh
RENPY_TOOL=/Applications/renpy-8.5.2-sdk/renpy.sh
```

## Измените исполняемые файлы в Схемах

1. На верхней панели Xcode нажмите на «DDLCModTemplate > My Mac» _(Мод-шаблон DDLC > Мой Mac)_ и выберите «Edit Scheme» _(Изменить схему)_.
2. На панели сведений в разделе «Run» _(Запуск)_ нажмите на поле **Executable** _(Исполняемый файл)_ и выберите «Other» _(Другое)_. 
3. Появится окно выбора файла; зайдите в папку, куда распаковывали Ren'Py, и выберите файл `renpy.app`.

## Проверьте изменения

Когда вы сделаете вышеописанные изменения и докинете файлы оригинальной игры, необходимые для работы мод-шаблона, нажмите на кнопку запуска или прожмите сочетание клавиш Command+R, чтобы проверить процедуру сборки/запуска.

Если процесс всё равно оканчивается неудачей, просмотрите [обучение](https://web.archive.org/web/20230606025553/https://marquiskurt.net/2019/06/09/post.html) и убедитесь, что параметры проекта заданы корректно.

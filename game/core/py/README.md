# Содержание папки `core/py`

## Папки
- **\_\_pycache\_\_**: Содержит скомпилированные аналоги скриптов Python, отвечающих за основные функции оригинальной игры и мод-шаблона. Как правило, этой папки не должно быть ни в вашей модификации, ни в упакованном мод-шаблоне, но если она есть, не обращайте внимания.

## Файлы
- **README.md**: Файл, который вы сейчас читаете.
- **\_\_init\_\_.py**: Пустой файл, используемый в целях тестирования.
- **[0cleanup_ren.py](./0cleanup_ren.py)**: Содержит код, который удаляет устаревшие/перенесённые функции из оригинальной игры или мод-шаблона.
- **[0imports_ren.py](./0imports_ren.py)**: Содержит импорты для работы основных функций оригинальной игры и мод-шаблона.
- **[renpy_patches_ren.py](./renpy_patches_ren.py)**: Содержит некоторые патчи, необходимые для корректной работы оригинальной игры на Ren'Py 8.
- **[template_checks_ren.py](./template_checks_ren.py)**: Содержит кастомные исключения и проверки мод-шаблона для корректной работы последнего. В этом файле объединён функционал скриптов *exceptions.rpy* и *lockdown_check.rpy* из старых версий мод-шаблона.
